Objetivo: ensamblar el genoma de un eucariota diploide con lecturas de PacBio de alta fidelidad.

Primero debemos desargarnos el programa Hifiasm en bash y después tenemos que hacer que esté disponible en la PATH de forma permanente.

Vamos a trabajar a partir de un archivo que contiene lecturas HiFi de una planta, que se han tomado con la tecnología PacBio. Estos datos son un archivo FASTA (alta calidad) y se encuentra dentro de la carpeta “data”.

zgrep -c "^>" ../../data/At4.10.fa.gz #el comando zgrep cuenta dentro de un archivo comprimido (z). -c es la funcion contar "^>" las lineas que empiecen por >(todas  las lecturas comienzan por ese simbolo).

Hay 13812 secuencias dentro del archivo

¿Qué longitudes mínima, media y máxima tienen las secuencias? Se puede calcular con el siguiente comando:

zcat ../../data/At4.10.fa.gz | awk ' #awk es una herramienta de procesamiento de texto que lee los archivos linea por linea, los divide en campos y aplica las reglas que tu le digas.
BEGIN {min=1e12; max=0; sum=0; len=0; n=0}
{
  if ($0 ~ /^>/) {
    if (len > 0) {
      if (len < min) min = len
      if (len > max) max = len
      sum += len
      n++
    }
    len = 0
  } else {
    len += length($0)
  }
}
END {
  # última secuencia
  if (len > 0) {
    if (len < min) min = len
    if (len > max) max = len
    sum += len
    n++
  }
  print "Secuencias:", n
  print "Longitud mínima:", min
  print "Longitud media:", sum/n
  print "Longitud máxima:", max
}'
Secuencias: 13812

Longitud máxima: 59075

Si se estimara que el genoma a ensamblar fuera de sólo 19 millones de bases, ¿cuál sería la cobertura esperada?

La cobertura es el número de veces que se ha leído cada base de la secuencia, aunque la realidad es que la lectura suele ser dispersa. Habrá sitios que habrán sido leídos 30 veces y otros solo 2. Se calcula como el número total de bases secuenciadas entre el tamaño del genoma:

Cobertura = 250599484/19000000 = 13.18945

#Ensamblaje Creamos la carpeta “asm1” donde guardaremos los archivos de lasida que produzca el programa hifiasm.

export PATH=$PATH:~/bin/hifiasm
if [ ! -e asm1/At4.bp.p_ctg.gfa ]; then
   hifiasm -o asm1/At4 -t 2 -f 0 ../../data/At4.10.fa.gz 2> asm1/hifiasm.log
fi
